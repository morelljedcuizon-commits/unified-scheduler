# Security reports

Report a suspected security issue privately to **cuizon.morell@gmail.com**, the publisher's supplied support/privacy contact. Describe the affected version, behavior and safe reproduction steps. Do not include live access/refresh tokens, OAuth codes, private Moodle calendar URLs, personal calendars or database copies. Response times are not guaranteed.

Please avoid disclosing credentials or private calendar information in public GitHub issues. If a real credential has already been exposed, revoke or regenerate it through Google/Moodle and tell the publisher the affected file/commit or artifact location without copying the value again. Deleting a current file alone does not remove it from Git history or downloaded artifacts.

See [the bounded repository review](docs/SECURITY_REVIEW.md) for the local history reviewed during release preparation and its limitations. No Google verification, security certification or audit guarantee is implied. A packaged Desktop OAuth client identifies this public desktop application; private user authorization tokens must remain in the OS credential store and must never be committed or packaged.
